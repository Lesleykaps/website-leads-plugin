# Example prompts and expected boundaries

- **Run research:** “Find 20 qualified website-improvement leads in Manchester, UK, excluding hospitality.” Expected: asks or confirms persistence, researches varied sectors, returns XLSX/evidence and counts; no outreach.
- **Audit supplied businesses:** “Audit this CSV of businesses in Nairobi for observable website issues.” Expected: verifies claims, returns qualified/review split; does not infer missing contacts.
- **Configure persistence:** “Use local-only historical dedupe at this private folder.” Expected: confirms that the registry stays local and creates no remote account.
- **Remote persistence:** “Connect our team registry.” Expected: describes data transfer and requires authentication and consent before write; stops if the backend is not configured.
- **Delete local research data:** “Delete my local Website Leads run data.” Expected: identifies the configured private data path, confirms scope when needed, and reports what was removed.
