# Public submission checklist

- [ ] Replace contributor metadata with the legal publisher name and support email.
- [ ] Host and link public homepage, source repository, privacy policy, and terms of service.
- [ ] Test install and all starter prompts in a clean ChatGPT/Codex environment.
- [ ] Verify XLSX rendering, evidence ZIP paths, failed-browser behavior, and no-contact safeguards.
- [ ] If adding an MCP service: deploy HTTPS; complete authentication, consent, rate-limit, isolation, retention/deletion, audit-log, security, and prompt-injection testing; then add `mcp.json`.
- [ ] Submit the skills-only package through the OpenAI plugin submission portal, including publisher and review information.
- [ ] Address review feedback; publish only after approval.
