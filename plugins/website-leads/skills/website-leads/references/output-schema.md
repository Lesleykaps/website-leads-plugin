# Excel and evidence output

Create an `.xlsx` with exactly four sheets: `Qualified Leads`, `Evidence`, `Review Needed`, and `Search Summary`. Use tables, filters, frozen headers, readable widths, wrapped evidence notes, typed dates/numbers, and plain-text auditable URLs.

`Qualified Leads` includes identity/geography; status and factual problem summary; public email/phone; `Contact Route` (`email`, `phone_research`, or `manual_review`); six component scores, total, rationale, priority, confidence; business-specific fact and URL; recommended service; suggested pitch angle; and `Outreach Status = Not contacted`. Filter `Contact Route = email` only when a valid, publicly advertised email has evidence; phone-only never implies WhatsApp capability.

`Evidence` has one row per qualified lead with website URL, verified problems, severity, mobile status, primary/additional/evidence/contact URLs, screenshot paths, automated checks, branded/replacement-domain searches and outcomes, activity evidence, reconciliation notes, and research notes. Every screenshot path must resolve inside the evidence ZIP.

`Review Needed` records a genuine unresolved reason and next check. `Search Summary` reconciles targets, candidates, status/industry distributions, email-eligible and phone-research counts, exclusions, all dedupe counts, limits reached, anomaly audits, and documented exhaustion.
