# Publish through GitHub Pages

1. Upload this folder's contents to the public GitHub repository `https://github.com/Lesleykaps/website-leads-plugin.git`.
2. In GitHub, open **Settings → Pages**, set **Source** to **GitHub Actions**, then push the `main` branch. The included workflow publishes the contents of `site/`.
3. Create a release tag such as `v1.0.0`. The plugin manifests already use the hosted Cipher Technologies homepage, privacy policy, and terms URLs.
4. Before public plugin submission, verify that `info@ciphertechnologies.co.zw` is monitored and that the repository has the exact current package.

For a custom domain, connect it in GitHub Pages first, verify its DNS ownership, and then replace the GitHub Pages URLs in the manifest. Do not use a URL you do not control.
